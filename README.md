# Cloud Computing & Azure Project – Fundamentals, Architecture & Hands‑On Labs

## Overview

This project was completed as part of the Microsoft Azure Data Fundamentals (DP-900) training course and demonstrates foundational knowledge of cloud computing, data storage, analytics, data visualisation, and modern data platforms using Microsoft Azure and Microsoft Fabric. The course included practical labs exploring Azure SQL Database, Azure Storage, Azure Cosmos DB, Microsoft Fabric, and Power BI.

- Platform as a Service (PaaS)
- Software as a Service (SaaS)

# Scenario Work: "Paws & Whiskers" Business

As part of the course, I completed a business scenario for **Paws & Whiskers**, a growing retail organisation looking to modernise its data platform and improve business reporting. 

## The project focused on:

- Customer data management
- Sales analysis
- Inventory management
- Data modelling
- Azure service recommendations
- Data governance and compliance
- Business intelligence solutions
- Scalability and future growth planning

## Recommended Azure services included:

- Azure SQL Database for structured business data
- Azure Storage for file and document storage
- Azure Data Factory for integration and automation
- Azure analytics services for reporting and trend analysis
- Power BI dashboards for management reporting

The scenario demonstrated how Microsoft Azure can help organisations move from spreadsheet-based processes to a modern cloud data platform.
